# aizen.detector — Web Frontend

The SvelteKit 5 web interface for **aizen.detector**, a real-time phishing detection and URL analysis suite.

## 🚀 Live Demo
- **Live Application**: [https://aizen-detector.vercel.app](https://aizen-detector.vercel.app)
- **Backend API**: [https://aizen-detector-api.vercel.app/api/v1](https://aizen-detector-api.vercel.app/api/v1)

---

## ✨ Features

- **Clean, Cyber UI**: Modern interface with instant URL safety inspection.
- **Explainable Results**: Comprehensive breakdown across Reputation, Security, Structure, and Network indicators.
- **Friday the Assistant**: Interactive paperclip assistant explaining warnings and risk factors.
- **SvelteKit 5**: High-performance SSR and client-side transitions.
- **Zero Tracking**: Privacy-first design with no analytics or cookies.

---

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

The frontend will run on `http://localhost:5173`.
